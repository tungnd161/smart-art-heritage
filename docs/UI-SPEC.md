# SMART ART HERITAGE – UI SPEC ĐÃ CHỐT

## Phong cách
- Landing page dạng infographic/sơ đồ hệ sinh thái.
- Phong cách giáo dục – Mĩ thuật – di sản.
- Flat design, card-based.
- Không dùng dark-tech, terminal UI hoặc nền đen.
- Không dùng gradient đỏ toàn trang.
- Font chính: Inter hoặc Roboto.
- Không dùng serif hoặc mono font cho nội dung chính.

## Màu sắc
- Nền chính: #FFFFFF
- Nền section nhạt: #EEF4FB
- Nền section xám nhạt: #F5F7FA
- Đỏ nâu chủ đạo: #8B1A1A
- Vàng nhấn: #F5A623
- AI: #1565C0
- 3D: #6A1B9A
- AR: #2E7D32
- Web: #E65100
- Dashboard: #1A237E
- Xưởng sáng tạo: nền #FFF0F5, viền #F48FB1
- AR Gallery: nền #FFF8E1
- Đánh giá: nền #F3F4FF

## Header desktop: 4 cột
1. Logo block: icon vuông bo góc, đỏ-cam, gợi di sản/mĩ thuật.
2. Tên SMART ART HERITAGE V1.0; tagline vàng:
   “KHÁM PHÁ DI SẢN – HỌC MĨ THUẬT – SÁNG TẠO TƯƠNG LAI”.
3. Công nghệ tích hợp: 4 icon tròn AI, 3D, AR, WEB.
4. Hành trình học tập: 6 bước ngang, có mũi tên nối; bước cuối là ngôi sao vàng.

## System Diagram
- Tiêu đề: SƠ ĐỒ HỆ THỐNG TỔNG THỂ.
- Desktop có 6 module nằm ngang, nối bằng mũi tên.
- Bên dưới là 6 UI preview/mockup tạo bằng HTML/CSS.
- Mobile có thể cuộn ngang hoặc thành grid 2 cột.
- Các module đã có chức năng phải link route thật.
- Các module chưa có phải ghi “Định hướng phát triển”.

## Module Row
Desktop có 4 cột:
1. Xưởng sáng tạo: nền hồng nhạt.
2. AR Gallery: nền vàng nhạt.
3. Đánh giá & phản tư: nền tím nhạt.
4. Dashboard giáo viên: nền navy, chữ trắng.

3D, AR, đánh giá và Dashboard nếu chưa hoạt động thật phải có nhãn:
- Demo giao diện
- Định hướng phát triển
- Chưa kích hoạt dữ liệu thực nghiệm

## Footer: 5 cột
1. 5 khu di sản với avatar tròn lấy từ dữ liệu thật.
2. Chức năng chính.
3. Thiết bị hỗ trợ.
4. Giá trị mang lại.
5. QR code dẫn đến https://smart-art-heritage.vercel.app/

## Responsive
- Header 4 cột chuyển thành các khối dọc trên mobile.
- Module 7/8/9/Dashboard xếp dọc.
- Footer chuyển 2 cột rồi 1 cột.
- Không có chữ nhỏ hơn 11px trên mobile.
